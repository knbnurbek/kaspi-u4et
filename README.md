# Учёт Kaspi-магазина — с логином для нескольких пользователей

Эта версия поддерживает **регистрацию и вход по email + паролю**. Каждый, кто
зарегистрируется, видит только свои собственные данные — твои знакомые с
Kaspi-магазинами могут завести себе аккаунт в том же приложении, и их цифры
никак не пересекутся с твоими.

Всего 3 шага: **база данных → публикация сайта → регистрация пользователей.**
Всё бесплатно, банковская карта не нужна.

---

## Шаг 1. Создать базу данных (Supabase) — 5 минут

1. Зайди на **supabase.com** → «Start your project» → зарегистрируйся.
2. Нажми **New project**. Название — любое, например `kaspi-tracker`. Пароль
   базы данных — любой, сохрани на всякий случай.
3. Подожди 1–2 минуты, пока проект создастся.
4. Слева открой **SQL Editor → New query**, вставь и нажми **Run**:

   ```sql
   create table kv (
     user_id uuid references auth.users(id) not null default auth.uid(),
     key text not null,
     value jsonb,
     updated_at timestamptz default now(),
     primary key (user_id, key)
   );

   alter table kv enable row level security;

   create policy "users manage their own rows"
     on kv for all
     using (auth.uid() = user_id)
     with check (auth.uid() = user_id);

   alter publication supabase_realtime add table kv;
   ```

   Это создаёт таблицу, где данные каждого пользователя изолированы —
   человек может читать и писать только свои строки (`user_id = его id`).

5. Слева открой **Authentication → Providers** — Email должен быть включён
   (включён по умолчанию).

   **Важно для быстрого старта:** зайди в **Authentication → Settings** и
   выключи **«Confirm email»** (подтверждение через письмо) — иначе каждый
   новый пользователь должен будет подтверждать почту по ссылке, прежде чем
   сможет войти. Если хочешь, чтобы это было включено (безопаснее) — оставь
   как есть, просто предупреди друзей, что после регистрации нужно проверить
   почту.

6. Слева открой **Project Settings → API**. Скопируй:
   - **Project URL**
   - **anon public key**

7. Открой файл `src/supabaseClient.js` и вставь их вместо
   `ВСТАВЬ_СВОЙ_PROJECT_URL` и `ВСТАВЬ_СВОЙ_ANON_KEY`.

---

## Шаг 2. Опубликовать сайт (Vercel) — 5 минут

1. Зайди на **vercel.com** → зарегистрируйся (можно через GitHub).
2. Загрузи этот проект в свой GitHub-репозиторий (через сайт github.com —
   просто перетащить файлы, или через GitHub Desktop).
3. В Vercel: **Add New → Project** → выбери репозиторий → **Deploy**.
4. Через минуту получишь ссылку вида
   `https://kaspi-tracker-xxxx.vercel.app` — общую для всех, кто будет
   регистрироваться.

---

## Шаг 3. Как это увидят твои знакомые

1. Отправляешь им ссылку на сайт.
2. Они открывают её, жмут **«Зарегистрироваться»**, вводят свою почту и
   пароль.
3. После входа видят **пустое** приложение — свои собственные данные, никак
   не связанные с твоими. Дальше всё работает так же: импорт из Kaspi,
   настройки окладов, дашборд, история.
4. Установка на телефон/Mac — так же, как раньше (Safari → «На экран
   Домой» / Chrome → «Установить приложение»).

---

## Важно понимать

- **Ты становишься администратором этого мини-сервиса.** Все данные лежат в
  твоём проекте Supabase — то есть технически ты можешь их увидеть через
  панель Supabase (Table Editor), хотя через само приложение каждый видит
  только своё. Если для друзей это важно — предупреди их об этом честно.
- Бесплатный тариф Supabase спокойно тянет несколько десятков пользователей
  с такими объёмами данных — платить не придётся, пока это не вырастет в
  нечто большое.
- Если кто-то забудет пароль — можно включить восстановление пароля через
  email (Supabase Auth это умеет из коробки), сейчас в этой версии кнопки
  «Забыли пароль» нет — могу добавить, если понадобится.

---

## Если что-то не работает

- **Не получается зарегистрироваться / войти** — проверь, что в
  `src/supabaseClient.js` правильные URL и ключ, и что Email-провайдер
  включён в Supabase.
- **После регистрации ничего не происходит** — скорее всего, включено
  «Confirm email» — проверь почту, перейди по ссылке, потом войди.
- Пришли мне текст ошибки — разберём вместе.
